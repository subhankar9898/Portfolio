## Overview
This repository hosts my personal portfolio website, designed to showcase my skills, projects, and experience as a Fullstack Web Developer, Frontend Developer. It serves as a central hub for potential employers and collaborators to learn more about me and view my work.

## Live Demo
You can view the live version of my portfolio here:
[https://subhankar9898.github.io/Portfolio/](https://subhankar9898.github.io/Portfolio/)

## Features
* **Responsive Design:** Optimized for various screen sizes, including desktops, tablets, and mobile devices.
* **About Me Section:** Provides an introduction to my background, skills, and professional interests.
* **Skills Section:** Highlights my technical proficiencies.
* **Projects Showcase:** Displays a collection of my key projects with brief descriptions and links.
* **Contact Form/Information:** Allows visitors to get in touch with me.

## Technologies Used
This project is built using foundational web technologies:

* **HTML5:** For structuring the content of the web pages.
* **CSS3:** For styling and layout, including responsive design.
* **JavaScript (Vanilla JS):** For interactive elements and dynamic content.

## Installation & Setup
To run this portfolio locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/subhankar9898/Portfolio.git](https://github.com/subhankar9898/Portfolio.git)
    ```
2.  **Navigate into the project directory:**
    ```bash
    cd Portfolio
    ```
3.  **Open `index.html`:**
    Simply open the `index.html` file in your preferred web browser.

## Usage
Once opened in your browser, you can navigate through the different sections of the portfolio to explore my work and learn more about my profile.
